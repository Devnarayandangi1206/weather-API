🌦️ Weather API Application

A simple and responsive Weather Forecasting Application that provides real-time weather information for any city using a Weather API.

🚀 Features
Real-time weather updates
Search weather by city name
Displays temperature, humidity, wind speed, and pressure
Responsive and user-friendly interface
Fast API response
Error handling for invalid city names
Mobile-friendly design
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
Fetch API
Weather API
📋 How It Works
Enter a city name.
Click the search button.
The application sends a request to the Weather API.
Weather data is returned in JSON format.
The application processes and displays:
Temperature
Humidity
Wind Speed
Pressure
Weather Condition

⚙️ Installation
Clone the repository:
git clone https://github.com/Devnarayandangi1206/We.git
Open the project folder.
Add your Weather API key in the JavaScript file.
Run weather.html in your browser.
